# 🎓 Hello SKKU App

> A simple Streamlit web app to display a greeting message.

---

## 📌 Overview
This project is a beginner-friendly Streamlit application.  
It shows how to build and run a simple web app.

---

## ✨ Features
- 🖥️ Display a title  
- 💬 Show a message  
- ⚡ Simple and fast  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  

---

## 🚀 How to Run

### 1. Install
```bash
pip install streamlit
```

### 2. Run
```bash
streamlit run app.py
```
